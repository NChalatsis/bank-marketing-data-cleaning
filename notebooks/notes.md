Το project μου αφορά το **data cleaning και το ETL processing δεδομένων από μια τραπεζική marketing καμπάνια**.

Ξεκινάω από ένα αρχικό CSV αρχείο που περιέχει περίπου **41.000 εγγραφές** με πληροφορίες για πελάτες, προηγούμενες και τρέχουσες καμπάνιες, αλλά και οικονομικούς δείκτες. Στόχος ήταν να μετατρέψω αυτά τα raw δεδομένα σε μια πιο καθαρή και οργανωμένη μορφή, κατάλληλη για εισαγωγή σε **PostgreSQL**.

Η διαδικασία ακολουθεί τα βασικά στάδια ενός **ETL pipeline**. Αρχικά φορτώνω τα δεδομένα με Python και pandas. Στη συνέχεια τα καθαρίζω και τα χωρίζω σε τρία διαφορετικά datasets: **client**, **campaign** και **economics**.

Στο cleaning κάνω, μεταξύ άλλων, standardization σε κατηγορικές τιμές, χειρισμό missing values, μετατροπή πεδίων σε boolean, δημιουργία μιας ενιαίας ημερομηνίας τελευταίας επικοινωνίας και έλεγχο των data types. Μετά πραγματοποιώ validations ώστε να βεβαιωθώ ότι τα IDs και ο αριθμός των εγγραφών παραμένουν σωστά και συνεπή μεταξύ των τριών datasets.

Τέλος, εξάγω τρία καθαρά CSV αρχεία, τα οποία μπορούν να χρησιμοποιηθούν είτε για περαιτέρω **data analysis**, είτε να φορτωθούν σε μια relational database.

Μέσα από αυτό το project ήθελα κυρίως να δείξω ότι μπορώ να πάρω ένα πραγματικό, μη επεξεργασμένο dataset και να δημιουργήσω ένα **reproducible data-cleaning pipeline**, χρησιμοποιώντας Python, pandas, validation και σωστή οργάνωση του project.
